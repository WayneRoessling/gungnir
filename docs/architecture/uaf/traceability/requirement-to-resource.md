# requirement-to-resource Requirement to resource

**UAF definition.** The traceability between architecture requirements and the crates that carry them.

**Purpose here.** Shows which crates a requirement is carried by and which requirements each crate answers for; a requirement carried by no crate is one the code does not yet touch.
