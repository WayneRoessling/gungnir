**Timing.** continuous; picture latency and staleness visible.

**Success.** every vessel in the approaches is a track with an identity or an anomaly flag; peers receive the picture within the agreed latency.

**Failure.** false tracks in clutter overwhelm the display; AIS spoofing accepted as truth; stale peer tracks shown as current.
